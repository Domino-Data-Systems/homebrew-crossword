# Domino Data Systems crossword tap

Public Homebrew tap for the crossword generator. The application source stays in a private repository. This tap publishes release builds and a manual page.

Apple Silicon macOS is supported for v0.1.0.

```sh
brew trust --tap Domino-Data-Systems/crossword
brew tap Domino-Data-Systems/crossword
brew install crossword
man crossword
```

Ollama must be running locally. The default model is `llama3.2`.
